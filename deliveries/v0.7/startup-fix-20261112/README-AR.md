# إصلاح افتتاح الهاتف — Network Copilot 0.7

التحديث مبني على مصدر جهازك الذي أرسلته في 12 نوفمبر 2026. يصلح مرحلة «شعار Android الثابت ثم افتتاحية الشبكة» على هاتف Android 10: نافذة النظام تصبح كحلية فقط، وFlutter يعرض الهوية المتحركة مرة واحدة خلال التهيئة الحقيقية. لا يوجد مؤقت انتظار جديد. تغيّر أربعة ملفات موارد Android وثلاثة ملفات توثيق فقط.

## التثبيت والبناء

1. فك هذه الحزمة في `D:\copilot-startup-fix`. أغلق أي Flutter run أو بناء Gradle جارٍ. أبقِ خادم Node وDocker وCHR كما تعمل الآن؛ لا تحتاج ترقية قاعدة البيانات أو إعادة تجهيز الحساب.
2. شغّل في PowerShell:

```powershell
node "D:\copilot-startup-fix\install.cjs" "D:\NetWork-Ai"
```

يُراجع المثبت جميع الملفات قبل الكتابة ويرفض أي تعديل محلي غير معروف، ويحفظ الأصل تحت `.copilot-update-backups\health-v07-…`. احتفظ بمسار `Backup:` المطبوع. إذا ظهرت رسالة توقف فلا تكمل البناء ولا تستبدل ملفاتك يدويًا.

3. والهاتف متصل ومصرّحًا له عبر USB، شغّل:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\copilot-startup-fix\build-phone.ps1" -ProjectRoot "D:\NetWork-Ai"
```

يستدعي السكربت Gradle 9.3.1 مباشرة من الكاش بوضع offline، مع منع تنزيل SDK وJava آليًا. لا يستخدم wrapper 9.1.0 ولا يغيّره. بعد نجاح البناء فقط يثبت APK بـ`adb install -r`، ويجهز USB reverse، ثم ينفذ force-stop ويفتح التطبيق لاختبار تشغيل بارد. force-stop يغلق العملية ويحفظ بيانات التطبيق. يستخدم البناء توقيع debug المحلي القائم ومعرف التطبيق نفسه. إذا نقص عنصر يتوقف؛ لا تمسح الكاش أو التطبيق ولا تشغل flutter clean.

## القبول على هاتفك

- التمهيد كحلي، ثم هوية الشبكة المتحركة مرة واحدة، دون شعار ثابت منفصل أو ومضة بيضاء أو انتظار مصطنع.
- الجلسة المحفوظة متاحة. عند طلب إعادة دخول طبيعية استخدم حسابك وTOTP الحاليين؛ لا تعِد إعداد المصادقة.
- ابدأ فحص صحة فعليًا وافتح نتيجته، ثم جرّب العودة من الخلفية.
- راجع المظهرين وتقليل الحركة. إذا بقي اختلاف بصري، احتفظ بالصورة أو مقطع قصير للانتقال قبل أي تعديل آخر.

لا يُغلق إصلاح الافتتاحية قبل هذا القبول. بعده نؤكد شرح نتائج الصحة بالذكاء الاصطناعي، ثم بقية القبول المفتوح؛ لا نبدأ وظيفة أخرى الآن.

## الرجوع عن هذا التحديث

أغلق Flutter أو أي بناء جارٍ. استخدم المسار الدقيق الذي طبعه المثبت:

```powershell
node "D:\copilot-startup-fix\rollback.cjs" "D:\NetWork-Ai" "D:\NetWork-Ai\.copilot-update-backups\health-v07-المسار-المطبوع"
```

يرجع ملفات الكود والتوثيق الخاصة بالتحديث فقط، ويرفض الكتابة فوق تعديل أحدث. لإرجاع APK نفسه بعد ذلك أعد سكربت build-phone.ps1 على الموارد المستعادة؛ تثبيت -r يحفظ البيانات. لا توجد خطوة رجوع لقاعدة البيانات لأن هذا التحديث لا يغيرها.

## حدود التحقق

تقرير verification.json يميز ما نُفذ في بيئة التطوير وما بقي على هاتفك. نجح بناء TypeScript و84 اختبار خادم مع PostgreSQL معزولة، وتجميع وربط موارد Android. لم يُبنَ APK كامل ولم تُعد اختبارات Flutter هنا، وسكربت PowerShell والبناء بالتوقيع المحلي يحتاجان التنفيذ على Windows. تقارير المصدر التاريخية لم تُحسب اختبارات جديدة.
