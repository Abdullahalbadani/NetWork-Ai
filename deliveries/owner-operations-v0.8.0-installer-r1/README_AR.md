# Network Copilot 0.8.0 — تصحيح المثبّت R1

[تنزيل ZIP المصحح](./network-copilot-owner-operations-0.8.0-installer-r1-20261113.zip?raw=true)

يعالج هذا التصحيح رفض الملف الأصلي runtime/v06/dependency-lock.json برسالة UNKNOWN_LOCAL_EDIT. كان الملف موجودًا في حزم التثبيت الأصلية لكنه مستبعدًا من حزمة جمع المصدر؛ عومل غيابه عن الجمع كأنه غياب عن جهاز المالك. صححنا بصمات خط الأساس في البيان والحمولة من حزم 0.6 و0.6.1 و0.7 الموثقة، مع استمرار رفض أي تعديل محلي مجهول.

كود التطبيق وruntime المجمّع مطابقان للحزمة السابقة. نجحت 16 حالة للمثبّت، بما فيها إعادة إنتاج الخطأ القديم، والتثبيت مرتين، وحفظ الكاش والتراخيص والإعدادات، والرجوع البايتّي، وBOM/CRLF، ورفض تعديل حقيقي على ملف القفل، وترحيل قاعدة تجريبية من المخطط 2 إلى 3 مع بقاء الحساب وTOTP والجلسة والأسرار. اختبارات الخادم الـ108 تخص التنفيذ نفسه ولم تُعد لهذا التصحيح الخاص بالمثبّت. تحقق Flutter وبناء APK وقبول الهاتف وCHR ما زالت تحتاج بيئة المالك.

استخرج في D:\copilot-integration-r1، وأوقف خادم Node مع إبقاء PostgreSQL/Docker يعمل، ثم:

```powershell
node "D:\copilot-integration-r1\install.cjs" "D:\NetWork-Ai"
if ($LASTEXITCODE -ne 0) { throw "توقف التحديث؛ لا تكمل البناء." }
```

لا تحذف ملف القفل ولا تعدّل compatibility.json. لا تحتاج إلى رجوع عن المحاولة التي توقفت قبل الكتابة. اتبع README_AR.md وINSTALLER_R1_AR.md داخل ZIP بعد نجاح التثبيت. يظل Gradle 9.3.1 من الكاش والتوقيع وadb install -r كما هو.
