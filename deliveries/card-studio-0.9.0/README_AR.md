# تحديث استوديو الكروت — Network Copilot 0.9.0+11

هذه حزمة تحديث للمشروع القائم، وليست مشروعًا جديدًا. خط الأساس المقبول هو آخر نسخة أكد صاحب المشروع تثبيتها: **0.8.2+10 / مخطط PostgreSQL5**. تحتوي فروق المصدر والتشغيل الفعلي `runtime/v06` للوصول إلى **0.9.0+11 / مخطط6**، وتقبل تصحيح اختبار مركز التحكم R1 المعروف إن كان مطبقًا.

## 1. فك الحزمة ثم تطبيقها

استخرج محتويات ZIP داخل `D:\copilot-card-studio`. يجب أن يكون الملف `D:\copilot-card-studio\install.cjs` موجودًا مباشرة. لا تستخرجها فوق مشروعك. أوقف خادم Node القديم وFlutter في نافذتيهما بـCtrl+C، واترك PostgreSQL/Docker يعملان.

في PowerShell نفّذ:

```powershell
node "D:\copilot-card-studio\install.cjs" "D:\NetWork-Ai"
if ($LASTEXITCODE -ne 0) { throw "توقف التحديث؛ لا تكمل. أرسل نص النتيجة." }
```

يتحقق المثبّت قبل كتابة الكود من بصمات الحمولة والتشغيل وملفات خط الأساس وحالة المنفذ3443 وجاهزية قاعدة5 أو6 وصلاحيات حساب التشغيل. يحفظ الملفات الأصلية في `.copilot-update-backups\studio-v090-*`، ثم ينشئ نسخة بيانات مشفرة `before-studio-*.ncbak` في مجلدك الخاص قبل ترحيل5→6. التكرار آمن ولا ينشئ حسابات أو يكرر الترحيل. تُحفظ الملفات المعدلة فقط في مواضعها الأصلية.

لا توجد عملية npm install أو ترقية تبعيات أو تغيير wrapper أو مفاتيح التوقيع أو `.env` أو إعداداتك الخاصة. الحساب وMFA والجلسات وأسرار الراوتر والكاش وإصلاح الافتتاحية المثبت محفوظة. لا يكتب التثبيت أو التصميم أو إخراج PDF على الراوتر. لا تتضمن هذه الحزمة مفاتيح أو إعدادات أو بيانات صاحب المشروع.

لفحص التوافق فقط، دون كتابة أو ترحيل:

```powershell
node "D:\copilot-card-studio\install.cjs" "D:\NetWork-Ai" --check
```

إذا ظهرت `UNKNOWN_LOCAL_EDIT` فلا تتجاوزها ولا تحذف الملف؛ أرسل مساره ونص النتيجة. لم تُكتب ملفات عند رفض فحص التوافق. إذا فشلت جاهزية البيانات قبل الكتابة، صحح تشغيل قاعدة البيانات أو مسار إعداداتها ثم أعد الأمر نفسه. إذا ظهر `DATABASE UPGRADE INCOMPLETE` بعد تركيب الكود، أبق الخادم متوقفًا واحتفظ بالنسختين وأعد التثبيت بعد معالجة السبب؛ لا تُرجع الكود عشوائيًا فوق قاعدة ربما أصبحت6.

## 2. تشغيل الخادم الجديد

في نافذة مستقلة:

```powershell
Set-Location "D:\NetWork-Ai"
node --use-env-proxy --env-file=.env ".\runtime\v06\dist\server.js" --foundation
```

اتركها تعمل. المتوقع: `Network Copilot foundation is listening on https://127.0.0.1:3443`. إذا كان المنفذ مشغولًا فلا تشغّل خادمًا ثانيًا؛ أوقف القديم في نافذته أولًا. استعمل حسابك وشهادة المختبر الحاليين.

## 3. تجربة Chrome أولًا

في نافذة ثانية:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\copilot-card-studio\test-chrome.ps1" -ProjectRoot "D:\NetWork-Ai"
```

يستخدم Flutter المثبت ومسار كاش الحزم الحالي، ويشغّل التحليل والاختبارات ثم الويب دون CDN. عند الجاهزية افتح `http://127.0.0.1:52100`. يظهر **استوديو الكروت** في تنقل حساب الإدارة. على الهاتف يظهر تبويب **الكروت**. احتفظ بالدخول وMFA؛ لا تنشئ حسابًا جديدًا.

ابدأ بالمكتبة: اختر قالبًا، غيّر اسم الشبكة، حرّك الحقول وغيّر الألوان، احفظه ثم افتح معاينةA4. هذه المرحلة تستخدم بيانات عرض واضحة ولا تنشئ كروتًا على الراوتر. دليل كل خطوة في [FIELD_ACCEPTANCE_AR.md](FIELD_ACCEPTANCE_AR.md)، ووصف الوظائف والقرارات في [FEATURES_AR.md](FEATURES_AR.md).

## 4. بناء الهاتف من الكاش نفسه

بعد نجاح التحقق، وصّل الهاتف وأذن لتصحيح USB:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\copilot-card-studio\build-phone.ps1" -ProjectRoot "D:\NetWork-Ai"
```

يستدعي السكربت `gradle.bat` من كاش **gradle-9.3.1-all** مباشرة مع `--offline`، ولا يستدعي wrapper9.1 ولا ينزّل Gradle أو SDK. يستخدم Flutter الموجود في `android/local.properties`، ويفرض version0.9.0/code11. يثبّت بـ`adb -d install -r` مستخدمًا إعداد التوقيع المحلي نفسه، ثم يعيد توجيه3443 ويشغّل التطبيق. لم تتغير applicationId أو ملفات توقيعك. إذا غاب عنصر من الكاش يتوقف برسالة بدل تنزيل بديل.

يمكن البناء دون تثبيت باستخدام `-BuildOnly` مع الأمر السابق. لا تحذف التطبيق عند فشل المساحة أو التوقيع؛ احتفظ ببياناته وأرسل الخطأ.

إذا انفصل USB بعد نجاح التثبيت، أعد الارتباط دون بناء:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\copilot-card-studio\connect-phone.ps1"
```

هذا ينفّذ `adb reverse tcp:3443 tcp:3443`، ويعمل الربط في الخلفية ما دام USB/ADB متصلًا. أبق الخادم يعمل على الكمبيوتر. مجرد تثبيت APK لا ينشئ هذا الارتباط بعد إعادة تشغيلADB أو فصل السلك.

## 5. إصدار الكروت والطباعة

من **الإصدار والطباعة**: اختر الراوتر، وأضف باقات مرتبطة بأسماء ملفاتHotspot الموجودة فعلًا، وسعرها بالريال اليمني وحصتها ومدة الاستخدام التراكمي. حدد سياسة توليد الأرقام/الحروف وطول الاسم وكلمة المرور أو الرمز الموحد. هذه سياسة صريحة وليست استنتاجًا من عينة حسابات.

الراوتر الحالي للقراءة؛ تنفيذ الإصدار يحتاج حساب إصدار مستقلًا محفوظًا مشفرًا، ومعاينة ثم اعتمادًا وتأكيدMFA. ابدأ بكرتين على CHR وفق دليل القبول؛ لا تبدأ بطلب كبير. يمكنك لاحقًا طلب1000 من فئة100 و500 من250 و100 من1000 في طلب واحد، مع متابعة وإلغاء المتبقي. التقسيم الداخلي يحافظ على حد500 حساب لكل دفعة.

اختر الدفعات المؤكدة للطباعة، والقالب الافتراضي أو قالبًا لكل سعر، والهوامش والمسافات والقص واتجاهA4. يبدأ كل سعر بورقة جديدة. بعد اكتمال التجهيز افتح **PDF الفعلي** ثم نزّله أو شاركه أو افتحه للطباعة. يلزم Chrome أوEdge المثبت على كمبيوتر الخادم؛ لا ينزّل التطبيق متصفحًا أو خطًا أو صورة. في المكتبة اختر **الحجم الفعلي100%** واطبع ورقة قبول واحدة أولًا.

المشاركة تفتح اختيار النظام/المتصفح؛ لا تُرسل الملفات تلقائيًا. وجود واتساب أو عارضPDF على الهاتف وقدرة مشاركة الملفات فيChrome يحتاجان التجربة عندك. ملفPDF يحتوي بيانات الدخول الفعلية؛ احفظه كما تحفظ دفتر كروتك. إعادة الطباعة تستخدم الحسابات نفسها ولا تولد تفعيلًا أو تحصيلًا جديدًا.

## 6. الرجوع والتعافي

أوقف الخادم والويب أولًا. لرجوع **ملفات الكود فقط** إلى ما قبل هذا التحديث:

```powershell
node "D:\copilot-card-studio\rollback.cjs" "D:\NetWork-Ai" --original
if ($LASTEXITCODE -ne 0) { throw "توقف الرجوع؛ احتفظ بالنسخ وأرسل النتيجة." }
```

يفحص الرجوع نسخ الملفات وبصماتها ويرفض تعديلًا محليًا لاحقًا بدل الكتابة فوقه. `--original` يختار أول نسخة تخص هذه الدفعة، ويعالج أيضًا حالة إصلاح تثبيت جزئي معروف. لا يخفض مخطط قاعدة البيانات. خادم0.8.2 يرفض قاعدة6 عمدًا.

لتشغيل0.8.2 بعد ترحيل ناجح، استعد **نسخة before-studio المشفرة** إلى قاعدة جديدة منفصلة، مع الاحتفاظ بمفتاح `backup-v1.key` وإعداد الاستعادة الخاص في مجلدك الخاص. بعد رجوع الكود، المثال التالي يختار أحدث نسخة قبل الاستوديو ويطبع مسار إعداد منفصل دون تعديل إعدادك النشط:

```powershell
Set-Location "D:\NetWork-Ai"
$copilotSnapshot = Get-ChildItem -LiteralPath "D:\network-copilot-private" -Filter "before-studio-*.ncbak" -File | Sort-Object LastWriteTime -Descending | Select-Object -First 1
if ($null -eq $copilotSnapshot) { throw "لم توجد نسخة ما قبل الاستوديو؛ توقف." }
$copilotRestoreDb = 'copilot_restore_studio_' + (Get-Date -Format 'yyMMddHHmmss')
node --env-file=.env ".\runtime\v06\scripts\restore-foundation.mjs" $copilotSnapshot.FullName $copilotRestoreDb
if ($LASTEXITCODE -ne 0) { throw "توقفت الاستعادة؛ لم تتحول قاعدة التشغيل." }
$env:COPILOT_FOUNDATION_CONFIG = "D:\network-copilot-private\$copilotRestoreDb.private.json"
node --use-env-proxy --env-file=.env ".\runtime\v06\dist\server.js" --foundation
```

القاعدة الجديدة تمثل لحظة النسخة قبل الترحيل؛ التغييرات اللاحقة تبقى في قاعدة6 الأصلية ولا تُدمج تلقائيًا. الحسابات وMFA والأسرار تستعاد، لكن جلسات القاعدة المستعادة تُلغى عمدًا؛ سجّل دخولك المعتاد دون إعادة تجهيزMFA. لا تحذف قاعدة6 أو ملف إعدادها. متغيرالإعداد أعلاه خاص بتلك النافذة؛ لإزالته بعد إيقاف الخادم: `Remove-Item Env:COPILOT_FOUNDATION_CONFIG`. أعد تركيب0.9.0 قبل تشغيل إعداد قاعدة6 مجددًا. الرجوع إلى APK0.8.2 أيضًا يحتاج APK القديم وتوقيعك؛ الحزمة لا تخزن مفتاحك ولا تصنع APK قديمًا.
