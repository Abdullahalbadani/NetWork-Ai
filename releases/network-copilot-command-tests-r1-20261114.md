# تصحيح اختبارات مركز التحكم R1

فوق تثبيت المالك المؤكد 0.8.2+10 / PostgreSQL 5، يحدّث ملفًا واحدًا فقط: apps/mobile/test/command_test.dart.

أبلغ المالك نجاح flutter analyze بلا ملاحظات، و71 اختبارًا ناجحًا و3 متخطاة وفشل اختبارين بسبب RenderFlex bottom overflow. كان الاختباران يضعان القسم الطويل مباشرة في Scaffold محدود الارتفاع، بينما مصدر الرئيسية يضعه داخل SingleChildScrollView. يطابق التصحيح مضيف الاختبار بالاستخدام الفعلي، ويقلل ارتفاعه إلى640، ويبقي كشف استثناءات العرض وفحوص YER والمجهول وعدم ادعاء التحصيل. يضيف4 حالات للرئيسية بحساب المالك وسجل30يومًا، منها844×360 مع نص2×، للتحقق من التمرير والوصول إلى آخر صف.

اجتازت الحزمة11مجموعة مثبت/رجوع من ZIPالمستخرج، وفحص قواعد Dart للملف المعدّل. لم تُنفذ Flutter analyze أو اختبارات Flutter المعدّلة هنا لعدم توفر SDK؛ test-chrome.ps1 يعيد الفحص الصارم بكاش المالك قبل تشغيل الويب. لا ادعاء بأن الاختبارين أصبحا ناجحين ميدانيًا قبل هذه النتيجة.

لا تغيير لكود الإنتاج أو runtime أو المخطط أو الحسابات أو MFA أو التبعيات أو الكاش أو الافتتاحية أو التوقيع؛ لا ترحيل أو كتابة RouterOS أو إعادة بناء هاتف مطلوبة لتصحيح ملف اختبار. يحفظ المثبّت الملف الأصلي ويرفض اختلافًا مجهولًا ويوفر الرجوع. تبقى نافذة الخادم مفتوحة أثناء تطبيقه.
