# أداة تشخيص التوافق فقط

الحزمة الجديدة تحتوي الأداة وبصمات الملفات فقط؛ أُزيلت جميع نسخ المصدر المرجعية من التسليم. لا reference.ncp ولا محتوى ملفات المشروع ضمن ZIP. المراجع، إن احتاجها فحص Dart، تُقرأ من حزمة R2 الموجودة على جهاز المالك ولا تُرسل إلى أي خدمة. لا تغيير للمشروع أو إعداداته أو قاعدة البيانات ولا تجاوز لحماية المثبّت أو تنزيل SDK.

استخرجها في D:\copilot-inspect ثم شغّل:

```powershell
node "D:\copilot-inspect\inspect.cjs" "D:\NetWork-Ai"
```

يعرض جميع التعارضات دفعة واحدة وبصماتها، ويميز اختلاف تنسيق JSON عن تغيير الحقول والتبعيات. أرسل الناتج للمراجعة. تسع حالات تشخيص ناجحة هنا؛ فحص العملية الخارجية استعمل بديلًا لاختبار إدارة العملية فقط، ولا ادعاء بتنفيذ Dart حقيقي في بيئة التسليم.
